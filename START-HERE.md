### Managing Updates

**When you make changes to hymns/app:**

1. Build new version:
   ```bash
   npm run build:corpus
   eas build --platform android --profile preview
   ```

2. New APK link will be generated automatically

3. Tell users: "New version available! Install over old one"

4. Or use PWA - updates are instant (no user action needed)
