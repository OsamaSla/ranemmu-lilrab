## 30. First-run onboarding + UI approachability demo (2026-11-23, local commit 02a87513)

Owner asked for "Option C" — a working demo of onboarding + UI improvements — before deciding whether to keep it. Built locally, **not pushed**; it can be reverted with `git revert 02a87513` if rejected. (An earlier GUI demo was fully reverted on request — §8 — so do not assume this one is permanent.)

- `src/components/onboarding/OnboardingFlow.tsx` — 4-stage overlay: welcome (4 value cards) → book picker (covers, count, persisted via `setBook`) → 4-step feature tour with mini illustrations → 3 gesture hints (swipe language, rail tap, fullscreen). No route of its own: rendered from the root layout as a full-screen overlay, so no incomplete navigation stack.
- `src/hooks/useOnboarding.ts` — module-level store with `useSyncExternalStore` so the root layout and Help screen share one flag. **Gotcha:** the first version returned `{ ...state, complete, replay }`, where the `complete` *function* overwrote `state.complete` (boolean) — the overlay never showed. The boolean is now exposed as `isComplete`. Storage key `ranemmu.onboarding.v1` in AsyncStorage; a failed read fails open so storage errors cannot trap returning readers.
- `src/hooks/useFeatureHint.ts` — per-screen hint counter (max 3 shows) stored as `ranemmu.hint.<id>`; `src/components/CoachHint.tsx` is the dismissible one-line banner built on it.
- Integration points: `src/app/_layout.tsx` (splash waits for `loaded`, overlay while `!isComplete`); `library.tsx` (search hint); `hymn/[id].tsx` (swipe hint in normal mode only); `help.tsx` (practice card, "try it now" buttons, "replay the tour"); `index.tsx` (4 quick-action pills + "continue reading" from the last 3 recents); `favorites.tsx`/`recents.tsx` (actionable empty states).
- `EmptyState` gained optional `actionLabel`/`onAction` — backwards compatible with all existing callers.
- i18n: `onboarding.*`, `coach.*`, `home.quick*`, `home.continueReading`, `common.next/skip/done/tryIt`, `help.practiceTitle/practiceBody/replayTour` added to ar/en/de together (ar is the typed source of truth).
