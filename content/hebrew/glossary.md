# Hebrew glossary & house style — Book 2 (taranim)

Working reference for the hand-authored liturgical Hebrew. The point is
mechanical consistency: a batch must not re-invent a rendering that an earlier
hymn already fixed. When a new word is settled, add it here in the same commit
as the hymn that needed it.

Sources of authority, in order: **the Arabic** → the printed English (bridge
only) → the concordance echo noted below. Where Arabic and English disagree,
Arabic wins.

## Fixed renderings

| --- | --- | --- |
| يسوع | יֵשׁוּעַ | **Never `בישו`**, never `ישו`. Always pointed, always full spelling. |
| الرب | הָאָדוֹן / אֲדֹנָי | `אֲדֹנָי` in direct address; `הָאָדוֹן` when speaking about Him. |
| الله / الإله | אֵל / אֱלֹהִים | Construct chains: `אֵל עוֹלָם`, `אֱלֹהֵי יִשְׂרָאֵל`. |
| سلام لك (greeting) | שָׁלוֹם לְךָ | Fixed formula; do not vary to `שלום עליך`. |
| نعمة | חֶסֶד | Covenant-love, not `נועם`. |
| مجد / أمجد | כָּבוֹד / נֶהְדָּר | `מַה־נֶּהְדָּר` = "how glorious". |
| فداء / فدى / الفادي | פְּדוּת / פָּדָה / פּוֹדֶה | `גֹּאֵל` only where the sense is kinsman-redeemer. |
| خلاص / نجاة | יְשׁוּעָה | Also the root pun on the Name; keep `יֵשׁוּעַ` and `יְשׁוּעָה` distinct in one stanza. |
| كاهن عظيم | כֹּהֵן גָּדוֹל | Fixed; never `כהן ראשי`. |
| صليب | צְלָב | Post-biblical loan, but the only usable word in a hymn; `עֵץ` only when "wood/tree" is meant, never `תְּלִיָּה` (hanging). |

| اشترى / اقتنى | קָנָה | Cultic "acquired"; `קָנָנִי` in the refrain of tr0009. |
| شفيع / يشفع | מַפְגִּיעַ | Hiph'il of פגע, Isa 53:12. The fixed word for intercession. |
| ملجأ / حصن | מַחֲסֶה / מִבְצָר | `מַחֲסֶה` = refuge, `מִבְצָר` = fortress. |
| برج حصين | מִגְדַּל־עֹז | Prov 18:10. Keep the construct, with maqaf. |
| دهن / طيب (poured) | שֶׁמֶן תּוּרַק | Song 1:3, quoted whole; do not paraphrase. |
| أصرف كالذهب (refining) | אֶצְרֹף … כַּזָּהָב | Mal 3:3 register. Keep the verb `צרף`, not `נקה`. |
| جند الجحيم / شيال | גְּדוּדֵי שְׁאוֹל | "Troops of Sheol", as in tr0001. |
| ضعف | חָלְשָׁה / חֻלְשָׁה | `וְאָחוּס עַל־חֻלְשָׁתְךָ` (tr0001) is the fixed mercy line. |
| الأبد / إلى الأبد | לָעַד / עַד־עַד / לְעוֹלָם וָעֶד | Rotate by metre, not at random: `לָעַד` is shortest. |
| خل / حبيب / ودود | דּוֹד / רֵעַ / יָדִיד | `דּוֹד` carries the Song-of-Songs charge; `רֵעַ` is the plain friend. |
| قريبًا / سريعًا | עוֹד מְעַט / מְהֵרָה | Isa 26:20 idiom for "soon". |
| قام (resurrection) | קָם / הֵקִים | `וְקָם` for He rose; `הֵקִים` for He raised (others). |
| صعد / العلى | עָלָה / מָרוֹם | `וְשָׁב אֶל־הַמָּרוֹם` for the ascension. |
| توبة / اعتراف | תְּשׁוּבָה / הִתְוַדּוּת | Post-biblical but liturgical-standard; biblical paraphrase where metre allows. |
| خطية / إثم / ذنب | חַטָּאת / עָוֺן / פֶּשַׁע | Keep the three distinct when the Arabic does. |
| غفر / سامح | סָלַח / מָחַל | `סָלַח` is the cultic word; `מָחַל` is post-biblical, avoid. |
| نفس | נֶפֶשׁ | Not `רוח` — the Arabic `نفس` is the whole living self. |
| روح | רוּחַ | Ambiguous by design (wind/spirit); disambiguate with the verb, not by changing the noun. |
| سلام (peace given) | שָׁלוֹם | `שָׁלוֹם לְךָ` only in greeting; otherwise bare `שָׁלוֹם`. |
| غاية (goal, Phil 3) | מַטָּרָה | Phil 3:14; `מַטָּרָתִי הַמָּשִׁיחַ` is the fixed refrain of tr0196. |
| ملك / مقتنى (possession) | קִנְיָן | Acquired property (Gen 23:18, Lev 25:16); pairs with `קָנָה`. |
| سجن / جب (prison) | סֹהַר / בּוֹר | `סֹהַר` is Joseph's prison (Gen 39:20); `בּוֹר` the pit/den (Dan 6). |
| لجة / غمر (deep) | מְצוּלָה | Ps 69:3; keep apart from `תְּהוֹם`. |
| قطر الشهاد (honeycomb) | נֹפֶת צוּפִים | Ps 19:11; fixed for the "sweet as honey" line. |
| رمام (corpses) | יְקָבִים | "Graves/bodies"; used for "dead as corpses" (tr0194 2:2). |
| أوصاف (traits) | אֳפָיִים | Job 41:4; the rare biblical noun, not `תְּכוּנוֹת`. |
| صخرة الدهور (Rock of Ages) | צוּר הָעוֹלָמִים | Deut 32:4; the divine Rock is `צוּר`, never `סֶלַע`. |
| خطر (peril) | סַכָּנָה | Mishnaic, but the only noun for Rom 8:35's κίνδυνος; kept inside the biblical tribulation list. |
| جسد / أجساد (body) | גְּוִיָּה | Biblical body/corpse (Gen 47:18, Judg 14:8); keeps the resurrection sense that `גוף` loses. |
| الجلجثة (Golgotha) | גָּלְגָּלְתָּא | Kept Aramaic as a place-name; do not Hebraise to "the skull place". |
| مقام (station, standing) | מַעֲמָד | Pairs with `עֲמִידָה`; used for the "station on high" of tr0211. |
| عرس (wedding) | חֲתֻנָּה | Song-of-Songs and Rev 19:7; never the Modern `חתונה`. |
| أمة / شعب مقتنى (acquired people) | עַם סְגֻלָּה | Exod 19:5, 1 Pet 2:9; kept as a title, not "a special people". |
| منية / مشألة (wish, petition) | מִשְׁאָלָה | Ps 20:6 (`כָּל־מִשְׁאֲלוֹתֶיךָ`); something asked of God, not merely wanted. |
| هول (dread) | בַּלָּהָה | Job 24:17, Ps 88:16; the terror-noun, not the vaguer `סכנה`. |
| قبة الأفلاك (vault of the skies) | כִּפָּה | Post-biblical for dome; kept because the Arabic's image is architectural. |
| وطن / موطن (homeland) | מוֹלֶדֶת | Gen 24:4, Ruth 2:11; the land one was born to, never `ארץ` alone. |
| إمكان (possibility) | אֶפְשָׁר | Mishnaic and the only word for it; kept because the line's subject *is* possibility. |
| عواطف (emotions) | רֶגֶשׁ / הֶרְגֵּשׁ | Job 12:5 only; no biblical category noun exists, so the post-biblical abstract is used sparingly. |
| معين / ينبوع (spring, fountain) | מַעְיָן | Ps 114:8, Prov 5:18; keep apart from `בְּאֵר` (well). |
| ملك / نصيب (portion, possession) | נַחֲלָה | Num 18:20; what is owned is also what is given. |
| صدى (echo) | הֵד | Job 37:4; used for "echo back to the Father" (tr0225 1:5). |
| مرساة (anchor) | עֹגֶן | Post-biblical noun, kept for the nautical metaphor (Heb 6:19 in Greek); the verb `עָגַן` exists only in the "rest" sense. |
| نعيم / قناعة (contentment) | נַחַת | Isa 30:15 (`בְּנַחַת וָשָׁלוֹם`), Eccl 6:5; quiet satisfaction, not the Modern `שביעות רצון`. |
| بخور (incense) | קְטֹרֶת | Ps 141:2, Rev 8:3–4; the cultic noun for prayer, never `קטורת` spelled loose. |
| بيان / تعبير (expression, utterance) | בִּטּוּי | Post-biblical, unavoidable for the abstract `بَيَان`; the verb is `ביטא`. |
| ربح / خسارة (profit / loss) | רֶוַח / הֶפְסֵד | Phil 3:7–8's accounting; `רֶוַח` is the biblical profit-noun, `הֶפְסֵד` post-biblical for loss. |
| رئيس السلام (Prince of Peace) | שַׂר־שָׁלוֹם | Isa 9:5; kept as a fixed title in the construct, not "a peaceful prince". |
| ناموس (law, Rom/Gal) | נָמוֹס | The Greek loan, as in the Rabbinic and Pauline Hebrew tradition; distinguishes the Torah-as-system from `תּוֹרָה`. |
| سرور / لذة (delight) | שַׁעֲשֻׁעַי | Ps 119:24,77 (`שַׁעֲשֻׁעָי`); the plural of the object of delight, kept for "what I delight in". |
| صفات (attributes, of God) | מִדּוֹת | Post-biblical for God's character (the thirteen `מִדּוֹת` of Exod 34:6–7); biblical Hebrew has no abstract noun, so this is the liturgical term. |
| هزيمة (defeat) | תְּבוּסָה | Post-biblical; used only where the line needs a noun for defeat, since biblical Hebrew expresses it verbally (`נִגַּף`, `נָפַל`). |
| رضيع (suckling) | עוֹלֵל | Isa 49:15 (`עוּלָהּ`), Lam 2:11; the infant at the breast, not the general `תִּינוֹק`. |
| فدية / كفارة (ransom) | כֹּפֶר | Exod 30:12, Prov 21:18; the price of a life, kept distinct from `פְּדוּת` (the act of redemption). |
| حال / وضع (situation, state) | מָצָב | Post-biblical for a circumstance; used where the Arabic has `حَال` and no biblical noun fits the line. |
| شهوة / شوق (desire, longing) | תַּאֲוָה | Ps 10:3, 21:3; the object that fills the heart, not a vague emotion. |
| رواية / سرد (tale, narrative) | סִפּוּר | Post-biblical for a recounted account; kept for the hymn's "love tale" refrain, where `סֵפֶר` would suggest a written book. |
| اختطاف (rapture, snatching away) | חֲטִיפָה | Post-biblical; the noun for being caught up (1 Thess 4:17), used when the line needs the event and not a paraphrase. |
| حنين / شوق (yearning) | כְּמִיהָה | Post-biblical for the ache of longing; used where biblical Hebrew has only the verb `כָּמַהּ` (Ps 42:2) and the line needs a noun. |
| أثر / رسم (impress, mark) | רֹשֶׁם | Post-biblical for a visible trace; kept for the marks of the wounds, where the biblical `רָשַׁם` supplies no noun. |
| منزل / مسكن (dwelling) | מָדוֹר | Mishnaic for an abode; used for the prepared place of John 14:2, where `מָעוֹן` would sound like the temple. |
| نصر / انتصار (victory) | נִצָּחוֹן | Post-biblical noun; the biblical language expresses victory verbally (`נָצַח`, `יָשַׁע`), so this is used only where the line needs the abstract. |
| حمل الله (Lamb of God) | שֵׂה הָאֱלֹהִים | John 1:29's fixed title; never `حَمَل` as a common noun when it is a name. |
| فدية / فداء (ransom, redemption) | פִּדְיוֹן | Exod 21:30, Ps 49:8–9; the price paid, distinct from `פְּדוּת` (the act) and `כֹּפֶר` (the covering). |
| إكليل / تاج (crown) | עֲטֶרֶת | Prov 12:4, Isa 28:5; the wreath actually worn, kept for the thorn crown, where `כֶּתֶר` (a royal diadem) would make the mockery a coronation. |
| مسربل / متسربل (robed in) | עָטָה | Ps 104:2 (עֹטֶה אוֹר כַּשַּׂלְמָה), Isa 59:17; the verb already contains the garment, so no separate word for 'robe' is needed. |
| ساهر / فَلْنَصْحُ (keep vigil for prayer) | שָׁקַד | Jer 1:12, Ps 102:8; the watching verb, not merely 'to pray', where the Arabic keeps the vigilance. |
| أوصاف (traits, marks) | אֹפֶן | Post-biblical for a mode or aspect; used only where the Arabic lists the marks by which something is known, since biblical Hebrew has no noun for 'characteristic'. |
| صحبة (company, fellowship) | חֶבְרָה | Post-biblical for companionship (biblical `חֶבֶר` is a company of men, Hos 6:9); used when the line is about the Lord's company with the soul. |

## Pointing conventions

- Everything is **fully vocalised**. No unpointed word is allowed in
  `title_he` / `verses_he` / `chorus_he`; `hebrew-apply.mjs` rejects it.
- Maqaf `־` for genuine compounds and construct chains that read as one unit:
  `מִגְדַּל־עֹז`, `בֶּן־אָדָם`, `עַד־עַד`, `יֶשׁ־לָנוּ`. Do not use it as a
  hyphen for line breaks.
- Divine name: `יָהּ` is allowed in short liturgical lines; `אֲדֹנָי` and
  `אֱלֹהִים` elsewhere. The tetragrammaton appears only where the Arabic itself
  prints `يَهْوَه` (tr0091, tr0130, tr0143), because there the point is that the
  Name is applied to Jesus; do not substitute `אֲדֹנָי` in those lines.
- `יֵשׁוּעַ` keeps its final `ע` with patah; do not use the abbreviated `יֵשׁוּ`.
- Furtive patah stays on the final guttural: `רוּחַ`, `שָׁמֵחַ`, `מָשִׁיחַ`.
- Where a choice changes the tune, prefer the shorter pointing; note it in the
  payload's `review` array.

## Register rules

- Biblical/liturgical, not modern conversational. Banned as anachronisms:
  `מטוס`, `טלפון`, `אינטרנט`, `מחשב`, `פרויקט`, `בדרך כלל`, `בעצם`.
- Prefer construct chains over `של`: `דִּבְרֵי אֵל`, not `הדברים של אל`.
- Prefer the *vav-consecutive* for narrative ("and He…") and the plain
  imperfect for ongoing states.
- Parallelism is expected: A/B lines should mirror in syntax, not only in
  meaning. Keep the Arabic's own parallelism where it survives.
- No em-dashes, no parentheses, no quotation marks inside a line except `:`
  before direct speech (`אוֹמֵר לִי: הִנְנִי־חַי`).
- Christological titles keep their force: `בֶּן־אָדָם`, `כֶּבֶשׂ הָאֱלֹהִים`,
  `מֶלֶךְ הַכָּבוֹד`, `צֶמַח דָּוִד` are not softened to generic "servant".

## Batch workflow

1. Write `content/hebrew/taranim/NNNN.json`
   ```
   { "book": "taranim", "number": 7, "title_he": "…",
     "verses_he": [ { "label": "1", "lines": ["…"] } ],
     "chorus_he": "…",          // only when the hymn has a chorus
     "review": ["2:3 note — …"] }
   ```
2. `node scripts/hebrew-apply.mjs` — shape/pointing checks, then merge.
   `--check` proves the corpus is already in sync (safe pre-commit gate).
3. `node scripts/hebrew-meter.mjs --lines` — relative line balance; a flag is
   a prompt to re-read, not an automatic failure. `--strict` to gate.
4. `npm run build:corpus && npm run check:hymns && npm run typecheck`
5. Update `PROJECT_NOTES.md` §15 (count of translated hymns, any new decisions).

## Open decisions

- **Refrain hymns**: `chorus_he` should repeat the refrain text exactly in
  every stanza that carries `chorus: true`; the meter check ignores it. Settle
  on the first refrain hymn in Book 2 and record the rule here.
- **Dialogue hymns** (`يقول لي` / congregational reply): keep the speaker
  shifts but do not add speaker labels — the reader prints lines only.
- **Acrostics**: if Book 2 has one, the initial letters win over exact
  parallelism; note the compromise in `review`.
