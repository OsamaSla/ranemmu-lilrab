## 🚀 Quick Install (30 seconds!)

### For Android Users:

**Step 1:** Download APK file  
*(Save to Downloads folder)*

**Step 2:** Open your file manager  
→ Go to **Downloads** folder

**Step 3:** Tap the downloaded file  
`preview-*.apk` or `app-release.apk`

**Step 4:** Allow installation from Chrome/browser  
Toggle: **Allow from this source** → ON

**Step 5:** Tap **Install**  
Wait 10-15 seconds

**Step 6:** Find your icon! 🎉  
Look for blue/gold hymn icon on home screen

---

## ⚡ Alternative: Web App (No Installation Needed!)

1. Open Chrome and go to: https://osamsla.github.io/ranemmu-lilrab

2. Tap ⋮ (three dots) at top-right

3. Select **"Add to Home screen"**

4. Name it "Arabic Assembly Hymns" or "ترانيم"

5. Tap **Add**

**Done!** Works exactly like a native app, no download needed!

## 🌍 العربية (For Arabic Speakers):

**خطوات التثبيت السريع:**

1. حمل ملف APK من الروابط أدناه
2. افتح مدير الملفات → اذهب إلى مجلد التنزيلات
3. اضغط على الملف المحمل
4. سمح للتطبيق بالتثبيت من المتصفح
5. انتظر 10-15 ثانية
6. استمتع بتطبيقك مع الأيقونة الجميلة!

## ❓ Troubleshooting / أسئلة شائعة

| Problem | Solution |
|---------|----------|
| ❌ "Can't install" | Enable "Unknown sources" in Settings → Security |
| ❌ Wrong icon showing | Remove old icon → Reboot → Add again |
| ❌ App won't open | Requires Android 7.0+ (update phone OS) |
| ❌ Slow performance | Clear cache: Settings → Apps → Clear Storage |
