## 📦 Installation Guide

### For Android Users:

#### Method 1: Direct APK Install
1. Download the `.apk` or `.aab` file from links above
2. Open file manager → Go to **Downloads** folder
3. Tap the downloaded file
4. If prompted "Install from unknown sources", enable permission for Chrome/browser
5. Tap **Install** → Wait 10-15 seconds
6. Find app icon on home screen with your custom design!

#### Method 2: Expo Go (Alternative Testing)
1. Install **Expo Go** from Google Play Store
2. On your computer: `npx expo start --android`
3. Scan QR code shown in terminal
4. App runs instantly without installation!

### Troubleshooting:

**❌ "Can't install app"**
- Make sure you have enough storage space (~50 MB free)
- Enable "Install unknown apps" for your browser in Settings → Security
- Try uninstalling any previous version first

**❌ Wrong icon showing**
- Remove old icon from home screen (long-press → Remove)
- Reboot phone
- Add app again from app drawer

**❌ App crashes on opening**
- Requires Android 7.0+ (API 24+)
- Update to latest Android version if possible
